# Безопасность и поддержка

Скачивайте ORRYX Wizard из официальных выпусков этого репозитория.

Для сообщения о проблеме воспользуйтесь [поддержкой ORRYX](https://app.orryx.org/#/support-chat/new). Не отправляйте публично ссылку подписки, пароли роутера и Wi-Fi или данные аккаунта.

Панель управления предназначена для домашней сети.
