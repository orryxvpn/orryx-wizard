# ORRYX Wizard

Настройте ORRYX на домашнем Keenetic: авторизуйтесь или вставьте ссылку подписки вручную, подтвердите найденный роутер и выберите имя и пароль Wi-Fi. После авторизации поиск роутера начинается автоматически. Wizard проверит накопитель и сохранит настройки для восстановления.

Для настройки нужны Keenetic с поддержкой USB и Entware, подходящий накопитель, интернет и доступ администратора роутера. Если накопитель отсутствует или требует подготовки, Wizard покажет подсказку.

## Резервная копия

Перед настройкой выберите папку для ZIP с конфигурацией роутера; по умолчанию — рабочий стол. Штатная копия Keenetic и доступные файлы VPN сохраняются до изменений. Доступ к Keenetic и папка сохранения находятся на одном шаге. Копию можно пропустить кнопкой «Пропустить». Если выбрано сохранение, ошибка остановит настройку. Автоматические точки восстановления на роутере сохраняются.

## Авторизация

Кнопка «Авторизоваться» открывает обычный личный кабинет ORRYX. После входа поиск роутера начинается автоматически; если подписок несколько, выберите нужную. Ручной ввод ссылки также доступен.

## Панель ORRYX

После настройки откройте локальную панель кнопкой в Wizard: живые графики трафика и соединений, выбор серверов, смена ссылки подписки с резервной копией и проверка задержки. Срок подписки отображается по данным сервиса; кнопка «Продлить» открывает кабинет. Адрес и пароль панели появятся в конце настройки.

## Обновления

Wizard автоматически проверяет наличие новых выпусков и показывает уведомление. Нажмите «Обновить», чтобы загрузить новый выпуск и перезапустить приложение после установки. При переходе с версии 0.8.1 потребуется установить новый выпуск вручную.

Предварительный выпуск. Windows ARM64 требует дополнительной проверки на нативном устройстве. Возможности зависят от модели и версии KeeneticOS.
